# Small runnable example

Three species, two chromosomes each, eight directed links. Species B starts with its two chromosomes exchanged and one chromosome reversed relative to the others.

With the supplied starting layout, the midpoint crossing score is 10. Standard flip assistance reaches 8 with fixed order; full optimization reaches 0. All eight links remain present. This example is deliberately small so installation can be verified without external data downloads.

Run the commands in the repository README from the repository root.
