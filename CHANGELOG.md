# Changelog

## 0.1.0rc1

- Introduce `syntangle flip-assist` and `syntangle run` workflows with strict directed-link tables.
- Add the `SynTangleR` interface for both workflows on existing GENESPACE plot products.
- Report crossing counts, per-pair counts, twists, lower bounds, gaps, runtime and input hashes.
- Emit vector before/after PDFs with fixed internal coordinates and directed endpoints.
- Expose optional crossing-cap and combined ribbon objectives.
- Add runnable examples, input specifications, installation checks and user guides.
- Distinguish numerical solver bound closure from independent mathematical certification.
- Add experimental JCVI `.simple`/BED and minimap2 PAF converters with explicit filtering audits.
